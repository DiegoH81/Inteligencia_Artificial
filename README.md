# Artificial Intelligence

This repository hosts the projects from the **Artificial Intelligence** course. The focus is on learning AI foundations, all interfaces have been done using **OpenGL**.

**Author:** Diego Hidalgo

**Professor:** Juan Carlos Guiterrez Caceres

**Semester:** 2026-1 

## Projects
- `4_heuristicas.cpp`: Implementation of DFS, BFS, Hill Climbing, A* algorithms to find paths in a 20x20 grid.
- `n_en_raya\`: A project that consists in implementing a tic-tac-toe like game, that can vary its grid size. It has been implemented using Alpha-Beta prune algorithm.
